# N1N 图像生成工具（供 Agent 调用）

## 1. 来源

根据 N1N / llm-api.net 的 **创建 gpt-image-2-all** 文档实现：

- 文档页面：<https://llm-api.apifox.cn/459635301e0>
- API：`POST https://llm-api.net/v1/images/generations`
- 模型：`gpt-image-2-all`
- 请求：`model`、`size`、`n`、`prompt`、可选 `image[]`
- 响应：`created`、`data[]`，其中包含 `url` 和/或 `b64_json`

## 2. 文件

| 文件 | 作用 |
|---|---|
| `tools/llm-image-tool.mjs` | CLI 实现 |
| `tools/llm-image-tool.tool.json` | Agent 工具描述与 JSON Schema |
| `tools/test-llm-image-tool.mjs` | 本地 mock API 集成测试 |

## 3. 环境变量

```bash
# Windows PowerShell
$env:N1N_API_KEY = "你的密钥"

# macOS / Linux
export N1N_API_KEY="你的密钥"
```

可选的兼容变量：

- `LLM_API_KEY`：`N1N_API_KEY` 的备用变量
- `N1N_API_BASE`：默认 `https://llm-api.net`

**不要把密钥写在命令行参数、脚本、日志或提交记录中。**

## 4. 基本用法

```bash
node tools/llm-image-tool.mjs --prompt "一间黄昏书房中的玻璃仓鼠跑轮，暖光，电影感" --size 1536x1024 --n 1
```

输出为 JSON：

```json
{
  "ok": true,
  "model": "gpt-image-2-all",
  "size": "1536x1024",
  "n": 1,
  "created": 1776909189,
  "images": [
    {
      "index": 0,
      "url": "https://...webp",
      "revised_prompt": ""
    }
  ]
}
```

## 5. 下载图片

```bash
node tools/llm-image-tool.mjs   --prompt "..."   --download   --out-dir generated
```

下载的文件会出现在 `generated/image-01.webp` 等路径，JSON 的 `saved` 字段包含绝对路径。

## 6. 参考图

API 文档使用 **图片 URL**：

```bash
node tools/llm-image-tool.mjs   --prompt "将两张图合并为一张室内场景"   --image "https://example.com/a.png"   --image "https://example.com/b.jpg"
```

最多 5 张。

也支持本地文件：

```bash
node tools/llm-image-tool.mjs   --prompt "以这张图为参考"   --image-file "D:\assets\ref.png"
```

`--image-file` 会转成 data URL。**文档没有保证远程 API 接受 data URL**；优先使用可公开访问的 URL。

## 7. 固定 prompt 文件

适合 agent 传递长 prompt，避免 shell 引号问题：

```bash
node tools/llm-image-tool.mjs --prompt-file .\prompt.txt --size 1024x1024
```

## 8. 参数

| 参数 | 说明 |
|---|---|
| `--prompt, -p` | prompt，必填之一 |
| `--prompt-file` | 从 UTF-8 文件读取 prompt |
| `--model` | 默认 `gpt-image-2-all` |
| `--size` | `1024x1024` / `1536x1024` / `1024x1536` |
| `--n` | 1～4，默认 1 |
| `--image` | 参考图 URL，可重复，最多 5 |
| `--image-file` | 本地参考图，可重复 |
| `--download` | 下载结果 |
| `--out-dir` | 默认 `generated` |
| `--timeout` | 10～600 秒，默认 180 |
| `--max-retries` | 0～3，默认 2，仅对 429/5xx |
| `--dry-run` | 只打印脱敏请求，不联网 |
| `--help, -h` | 帮助 |

## 9. Agent 接入

工具描述在 `tools/llm-image-tool.tool.json`。Agent 侧可以把 CLI 包成 shell 工具：

```text
tool: n1n_generate_image
command: node tools/llm-image-tool.mjs
inputs: prompt, size, n, image[], download, out_dir
output: stdout JSON
```

调用示例：

```bash
node tools/llm-image-tool.mjs   --prompt "黄昏书房里的玻璃仓鼠跑轮，暖色灯光，广角，电影感"   --size 1536x1024   --n 1   --download   --out-dir generated
```

Agent 应读取 stdout JSON，只把 `images[].url` 或 `images[].saved` 当作结果，不要把 stderr 的 JSON 错误当成成功。

## 10. 错误码

| 错误码 | 含义 |
|---|---|
| `MISSING_PROMPT` / `EMPTY_PROMPT` | prompt 缺失或为空 |
| `INVALID_SIZE` | 尺寸不在允许列表 |
| `TOO_MANY_IMAGES` | 超过 5 张参考图 |
| `MISSING_API_KEY` | 未设置密钥 |
| `NETWORK_ERROR` | 超时或网络错误 |
| `API_ERROR` | 非 2xx，包含 HTTP 状态 |
| `INVALID_RESPONSE` | 响应没有 data 数组 |
| `IMAGE_FILE_ERROR` | 本地参考图读取失败 |

## 11. 测试

```bash
node tools/test-llm-image-tool.mjs
```

测试会启动本地 mock server，验证：

- 请求路径与模型
- prompt 与参考图数量
- 返回 JSON
- 图片下载与文件落盘

测试不需要真实 API Key，也不会访问 llm-api.net。

## 12. 安全与限制

- 不在命令行参数中传密钥；只从环境变量读取。
- 错误信息不打印 Authorization 头。
- 图片 URL 下载来自 API 返回，仍建议检查来源。
- 未在真实 N1N API 上测试；需要有效密钥后先做一次最小调用。
- API 可能按张数计费；`--n` 默认 1。
- 未实现上传接口；本地参考图使用 data URL 仅为便利，是否被接受取决于服务端。
