# 交互、时间与灯光系统

## 1. 控制状态

核心状态集中在 `CONTROL`：

```js
{
  target: 0.5,     // 鼠标/属性目标
  display: 0.5,    // 平滑后用于滑块与灯光
  speed: 1.0,      // 0.8 ~ 1.2
  bright: 1.0,     // 1.0 → 0.45
  hover: false,
  dragging: false
}
```

滑块位置、速度倍率、灯光颜色与强度都从 `display` 派生，不各自维护状态。

## 2. 鼠标映射

命中流程：

1. 鼠标坐标转 NDC。
2. Raycaster 与控制器不可见命中体求交。
3. 再把同一条射线投到滑块中心的竖直平面。
4. 把交点转换到控制器局部坐标，取局部 X。
5. 归一化并夹紧到 [0,1]。

没有直接使用 `clientX / window.innerWidth`，因此控制器旋转、透视和窗口缩放都不会破坏对应关系。

- 鼠标离开后保留当前值。
- 指针进入时使用 `ew-resize` 光标。
- 拖动时锁定已有镜头视差，避免同时带动镜头。
- 触屏使用 pointer capture。
- `CONTROL.setT(value)` 供调试和 Wallpaper Engine 属性使用。

## 3. 速度、相位与时间

基础媒体倍率为 **0.35**。控制倍率：

```text
speedMultiplier = 0.8 + 0.4 × t
```

每帧连续累积：

```js
animTime += dt × 0.35 × speedMultiplier
```

人物帧与轮体转角都从同一个 `animTime` 计算：

```text
mediaTime = animTime
fr = floor(mediaTime / cycle × 11) mod 11
angle = baseAngle − mediaTime × L / (T × R)
```

因此调整倍率不会跳相位。固定截图时用 `t × 0.35 × speed` 得到同一帧。

轮体参数：

```text
L = 0.068
T = 11 / 12 = 0.9167
R = 0.443
ω_media = 0.1675 rad/s
ω_real(1×) = 0.35 × 0.1675 = 0.0586 rad/s
```

真实时钟独立读取系统时间；`?clock=HH:MM` 只用于截图覆盖。

## 4. 灯光分组

### 联动装饰光

| 组 | 实现 | 位置/范围 |
|---|---|---|
| 轮缘/轮内 | 点光 + 现有 rimCatch | 跑轮内部 |
| 底座灯串 | 13 颗独立灯珠与光晕 | 木质底座外圈 |
| 尾线灯 | 3 颗不等距灯珠 | 控制器到底座 |
| 底座下缘 | 3 点光 + 桌面椭圆光斑 + 前缘溢光带 | 底座周围 |
| 窗台下方 | 聚光 + 墙面软渐变 | 左后墙 |
| 置物架下方 | 聚光 + 墙面软渐变 | 右后墙 |

### 稳定环境光

- 房间主光、台灯、墙面悬挂灯串、窗外天空。
- 不参与变阻器联动。

### 时间显示

- 普通小时：暖色 `#f7dbb0`
- 当前小时：冷蓝 `#b8edff`，放大 1.12
- 分钟点：`#78dfff`，核心 `#e4fbff`
- 数字 z=0.136，刻度环 z=0.120，分钟点 z=0.160
- 数字使用正常深度测试，不做全穿透

## 5. 颜色与亮度

```js
COOL   = 0x2fb6ff
NEUTRAL= 0xffc88a
VIOLET = 0xc25cff
bright = 1.0 - 0.55 × abs(2t - 1)
```

端点亮度 45%，中点 100%。平滑使用：

```js
k = 1 - exp(-12 × dt)
```

时间常数约 0.25 秒。

## 6. 灯珠

- 外壳半径 0.0120，核心 0.0055。
- 泛光有限，避免相邻光晕连成白带。
- 木面光斑与灯珠同色、同亮度趋势。
- 不为每颗灯珠创建实时点光源；新增实际光源共 5 个。

## 7. Wallpaper Engine 属性

```js
window.wallpaperPropertyListener = {
  applyUserProperties(properties) {
    if (properties.balance) {
      window.__setWallpaperBalance(properties.balance.value);
    }
  }
};
```

Balance 与场景滑块共享 `CONTROL.target`，不重置 `animTime`。
