# 场景与视觉设计

## 1. 场景结构

场景是一个黄昏室内书桌：

- 拱窗与窗外城市剪影位于左后方。
- 双层窗帘、墙面灯串、墙面搁板构成背景。
- 玻璃仓鼠跑轮位于中右区域，是绝对视觉中心。
- 桌面左侧有植物、书本与滑动变阻器，右侧有马克杯、碟子与瓜子。
- 左侧落地灯提供室内暖色主光。

相机参数保持固定：

```js
PerspectiveCamera(35, aspect, 0.05, 60)
CAM_BASE   = (0.16, 1.02, 3.32)
CAM_TARGET = (0.13, 0.68, 0.00)
```

## 2. 构图

按 1600×900 截图测量：

| 对象 | 屏幕位置 | 占比 |
|---|---:|---:|
| 跑轮中心 | x≈982 | 61.4% |
| 变阻器中心 | x≈523 | 32.7% |
| 植物 | x≈130 | 8.1% |
| 书本 | x≈359 | 22.4% |
| 马克杯 | 右侧偏内 | ~88% |

跑轮接近黄金分割 61.8%；控制器的 32.7% 落在 30%～38.2% 区间。右侧物件向内收，避免贴边。

## 3. 跑轮

主要比例：

```js
WHEEL_R = 0.460     // 外径 0.92
WHEEL_CY = 0.700
TRACK_R = 0.443
DRUM_HALF = 0.120
GLASS_R = 0.460
CLOCK_RING_R = 0.520
HOUR_NUM_R = 0.565
```

结构：

- 旋转组：滚筒玻璃壁、前后玻璃边缘、内部跑道、装饰轮缘。
- 固定组：后毛玻璃背板、香槟金支架、底座、固定钟面、人物。
- 透明材质使用较低不透明度与分层 renderOrder，前玻璃、轮缘、人物之间保留深度关系。

## 4. 人物

- 11 张 768×1024 RGBA 帧，统一画布，不逐帧裁切/缩放。
- 拼成 4×3 精灵图，最后一格为空；UV 子矩形切帧。
- 世界显示高度 0.400，脚底基准 y=0.264，身体锚点 x=389/768。
- 固定根节点，不叠加整体 bob/sway；步态起伏来自原始帧。
- 精灵图以 base64 内嵌，保证单文件可运行。

## 5. 变阻器

- 奶油白水平圆柱、黄铜端板/端环、上下滑轨、滚花滑块、红色指针。
- 固定刻度面：13 条短刻线、左「牢」右「圣」，文字由 CanvasTexture 生成。
- 整体宽度约 0.28，约为跑轮外径的 30%。
- 位置 `(-0.50, 0, 0.16)`，略微朝向镜头。
- 不可见命中体大于外观，便于鼠标/触屏操作。

## 6. 台灯

- 圆盘配重底座、毡垫、细黄铜弯杆、顶部关节。
- 开放式锥形灯罩：暖象牙外层、暖光内衬、上下黄铜收边。
- 灯泡位于灯罩内，底部有柔光；另有一个向下的柔和聚光，形成桌面光池。
- 原有照向跑轮的主聚光保留。

## 7. 氛围

- 暖色墙面、木桌、黄昏天空。
- 装饰光可变色，但房间主灯、落地灯和墙上灯串保持暖色。
- 时间数字独立冷蓝；只有当前小时和分钟点使用冷色。
- 台灯偏暖，不参与变阻器联动。
