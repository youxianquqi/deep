# 素材、音乐与来源说明

## 1. 角色走路帧

- 来源：项目提供者的 11 张 PNG 走路帧。
- 原始尺寸：768×1024，RGBA。
- 本仓库只做统一画布拼图，未重绘、未拆分肢体、未改比例。
- `assets/walk-sheet.png` 为 4×3 精灵图，最后一格留空。
- 帧原始顺序：`walk_01.png` … `walk_11.png`。
- 透明边缘、白描边和原始颜色在拼图过程中未做压缩处理。

## 2. 精灵图构建

`assets/walk-sheet.png`：

```text
尺寸：3072×3072
布局：4 列 × 3 行
单元：768×1024
有效帧：11
```

运行时使用 UV 子矩形切帧，不逐帧缩放。

## 3. 氛围音乐

- 文件名：`assets/ambience.mp3`
- 时长：96 秒
- 格式：MP3，160 kbps，44.1 kHz，立体声
- 内容：程序化合成的柔和 pad、低音持续音、稀疏拨弦
- 无人声、无第三方采样
- 生成脚本：`tools/make_ambience.py`
- 循环使用；文件首尾有约 2 秒淡入淡出

## 4. Three.js

- 版本：r149 UMD
- 文件：`src/three.min.js`
- 许可：MIT
- 页面内嵌，无 CDN 请求。

## 5. 参考图

- 滑动变阻器参考图由项目提供者提供。
- 仅参考外部轮廓、滑轨、滑块、材质与配色。
- 未使用参考图作为贴图，未加入内部电路或照片平面。
- 场景中不显示参考图、文字说明或标签。

## 6. 字体

- 控制器「牢 / 圣」：CanvasTexture + 系统 Microsoft YaHei/SimHei。
- 小时数字：CanvasTexture + Georgia/Times New Roman。
- 无外部字体文件。

## 7. 不随源码提交的内容

- 1 分钟 MP4 演示视频
- 录屏帧序列
- 壁纸 ZIP 压缩包
- 浏览器临时截图
- `ambience.wav` 原始 96 秒未压缩音频

如需发布视频或 ZIP，建议放入 GitHub Releases，而不是主分支。
