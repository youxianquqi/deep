# 构建与运行

## 1. 环境

- Windows / macOS / Linux
- Node.js 18 或更高
- 现代 Chromium 浏览器（Edge / Chrome）
- 无需 npm install；Three.js 已放在 `src/three.min.js`

## 2. 构建

在仓库根目录执行：

```bash
node build.mjs
```

脚本会：

1. 读取 `src/01-core.js` … `src/06-anim.js`。
2. 读取 `src/three.min.js` 与 `src/template.html`。
3. 把 `assets/walk-sheet.png` 转为 base64 内嵌。
4. 替换 `__WALK_SHEET_DATA__`。
5. 生成 `wallpaper/index.html`。
6. 复制 `assets/ambience.mp3` 到 `wallpaper/assets/ambience.mp3`。

构建后的 `wallpaper/` 即是可导入 Wallpaper Engine 的完整 Web 工程。

## 3. 直接运行

直接打开：

```text
wallpaper/index.html
```

页面不依赖服务器，精灵图与音频都使用相对路径。

注意：浏览器通常阻止无手势的有声自动播放。点击页面一次即可启动音乐。

## 4. 本地服务器

```bash
python -m http.server 8000
```

打开：

```text
http://127.0.0.1:8000/wallpaper/
```

## 5. 调试参数

| 参数 | 用途 |
|---|---|
| `?t=8` | 固定场景时间，便于复现某一帧 |
| `?clock=15:28` | 固定时间显示 |
| `?control=0` | 左端初始值 |
| `?control=1` | 右端初始值 |
| `?q=low` | 降低渲染分辨率 |
| `?view=wheel` | 使用已有视角预设 |

示例：

```text
index.html?t=8&clock=15:28&control=0
```

`?t` 会暂停动态时间，不是实时壁纸模式。正常观看不要带 `t`。

## 6. 源码模块

| 文件 | 职责 |
|---|---|
| `01-core.js` | 渲染器、相机、后期、材质/工具、窗口尺寸 |
| `02-textures.js` | 程序化贴图、阴影、光晕 |
| `03-materials.js` | 材质、几何工具、ANIM 注册表 |
| `04-world.js` | 房间、窗户、家具、台灯、灯串、陈设 |
| `05-wheel.js` | 跑轮、底座、钟面、控制器、灯光、人物精灵图 |
| `06-anim.js` | 相机、动画循环、时钟、灯光控制、音频、录制 API |

## 7. 生成文件与版本控制

建议仓库只跟踪：

- `src/`
- `assets/`
- `wallpaper/project.json`
- `wallpaper/preview.jpg`
- `wallpaper/index.html`（可选，构建产物）
- `docs/`

不要提交：

- `recording/recording2/` 帧序列
- `*.mp4`
- `*.zip`
- `*.wav`
- 浏览器缓存或临时截图

## 8. 验证

仓库内提供的基础验证方式：

1. 构建成功且输出 `wallpaper/index.html`。
2. 浏览器打开无 console error。
3. 检查 `?control=0` / `0.5` / `1` 三种灯光状态。
4. 检查 `?clock=08:00` 时 8 点高亮、其余暖色、9/10 点可见。
5. 用鼠标在控制器命中区域移动，确认滑块与数值同步。

自动化截图可以复用 `tools/shot.mjs`，但其中 Edge 路径和输出路径需要按本机修改。
