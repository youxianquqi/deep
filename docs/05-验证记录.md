# 验证记录与已知限制

## 1. 已完成的检查

### 浏览器运行

- 1600×900：canvas 2400×1350，场景正常，无 console error。
- 1366×768：canvas 2049×1152，场景正常。
- 1920×1080：用于录制时正常启动。
- 角色精灵图 3072×3072，纹理加载成功，UV 方向正确。
- 音频：`readyState=4`、`duration=96`、`loop=true`、`volume=0.14`、无解码错误。

### 控制与相位

- 鼠标在控制器外移动：target 保持 0.5。
- 鼠标进入滑轨：target 可精确设为 0.2，光标为 `ew-resize`。
- `?control=0`：速度 0.8、亮度 0.45、滑块 x≈−0.105。
- `?control=1`：速度 1.2、亮度 0.45、滑块 x≈0.105。
- 固定 t=8 时，中点/左端/右端媒体时间分别约 2.8 / 2.24 / 3.36。
- 实时相位测试：倍率 1.0 → 1.2 后单帧增量 0.00672，与 `0.016×0.35×1.2` 一致，无重置。

### 时间显示

- 普通小时：`#f7dbb0`
- 当前小时：`#b8edfe`
- 分钟点：`#78dffe`
- 15:28 时只有 3 点冷蓝，其余 11 个数字暖色。
- 08:00 时只有 8 点冷蓝，其余暖色。
- 8、9、10 点完整可见；5、6、7 未新增遮挡。

### 灯光

- 左端：底座前缘、桌面、窗台/置物架墙面和尾灯呈青蓝。
- 中点：暖白/香槟色承托光与墙面光。
- 右端：淡紫色桌面、墙面和尾灯。
- 房间主灯、落地灯、墙上灯串保持稳定暖色。
- 控制器命中区域不受新增灯线与灯珠影响。

### 台灯

- 灯罩无方形插座的错误轮廓。
- 底座、灯杆、锥形灯罩、暖光内衬、灯泡、上下黄铜收边可见。
- 台灯暖光不参与变阻器联动。

## 3. 已知实现取舍

- 灯光是“实际局部光源 + 贴面柔光”的组合，不是全局光照。
- 底座前缘溢光使用贴在桌面的渐变面，边缘经过柔化但仍属于近似。
- 墙面洗光使用低强度聚光与墙面加色渐变；没有光线追踪反弹。
- 0.35 基础速度下人物实际约 4.2 fps，慢速散步更明显，但帧间也更明显。
- 精灵图是 3072×3072 RGBA，HTML 约 9 MB。
- 音频边缘有 2 秒淡入淡出，循环处存在轻微安静过渡。

## 4. 复现建议

```text
index.html?t=8&clock=15:28&control=0
index.html?t=8&clock=15:28&control=1
index.html?clock=08:00
```

在 Wallpaper Engine 中：

1. 检查 Balance 属性是否能驱动滑块与灯光。
2. 尝试点击壁纸启动音频。
3. 检查 1366×768、1920×1080 和超宽屏下的裁切。
4. 观察长时间运行时是否有明显掉帧或显存增长。
